---
name: Design system migration
description: Conventions and pitfalls for migrating StreamAiX pages to the DESIGN.md token system
---

- DESIGN.md is the contract; ds/ primitives live in `client/src/components/ds/`. `npm run design:lint` is GLOBALLY enforced over all of client/src — the allowlist (`scripts/design-migrated.txt`) was removed once the whole tree was migrated.
- Lint boundary regex excludes `=` so radix selectors like `data-[motion=from-end]` aren't false positives; quoted classes are still caught (verified by fixture). Banned list includes legacy neutrals/accents (slate/gray/zinc/purple/violet/indigo/blue text+bg+border). Raw semantic colors (red/emerald/amber/cyan, ~500 instances) are intentionally NOT banned — flagged as possible future scope.
- Token naming deviations from the original spec (to avoid clobbering shadcn vars): the violet accent is `--accent-core` (not `--accent`); `text-primary/body/secondary/muted` are un-layered CSS overrides at the end of `index.css` that win over shadcn-generated utilities.
- **Why (historical):** during migration, redefining shadcn vars would have restyled unmigrated surfaces. Post-migration, the dark-theme shadcn vars ARE repointed at ink/accent values in `index.css` — that is now the intended state.
- Delegated bulk restyles (design subagents editing large tsx files) repeatedly produced corrupted className strings — missing closing quotes, duplicated tokens, invalid opacity forms like `gain/500/30`, empty variants (`hover: `, `data-[state=active]: `, `hover:hover:`), and even behavior changes (swapped image fallbacks). **How to apply:** design-lint now greps for these malformed patterns; still diff-review delegated output for non-class changes, and never run whitespace-collapsing seds (`s/  +/ /g`) on whole files — they destroy indentation.
- Authoritative tsc baseline: ~370 pre-existing errors repo-wide (cold cache). Gate new work by diffing error sets against a stored baseline log, not by exit code. Baseline copy kept at `.local/tsc-baseline.log` (/tmp copies get wiped). Line-number shifts make pre-existing errors look "new" in the diff — verify by stashing before treating as regressions.
- CSS var contract: tailwind.config.ts consumes shadcn vars as complete colors (`var(--border)`), so vars hold full hex/hsl() values — never HSL triples. Any `hsl(var(--x))` in component code is wrong under this contract; use `var(--x)` directly. Dark-theme shadcn vars are repointed at the ink palette so ui/ primitives inherit tokens.
