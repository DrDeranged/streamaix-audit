Build the non-custodial trading rail on Base. StreamAiX never holds keys
or funds — it quotes, the user's wallet signs.

1. WALLET: integrate wagmi v2 + viem + RainbowKit on Base (chainId 8453),
   with Coinbase Smart Wallet in the connector list. New ds-styled
   ConnectButton in the nav (ink surface, accent when connected, shows
   truncated address + Base logo). Persist connection state; a
   useWallet hook exposes address/chain/balances (ETH, USDC, WETH via
   viem multicall).
2. SWAP SERVICE (server/services/swapQuoteService.ts): wrap the 0x Swap
   API (Base) behind our server (API key server-side, never in client).
   getQuote({sellToken, buyToken, sellAmount, takerAddress}) returns
   price, guaranteed price, allowance target, and tx payload. Include
   the affiliate fee params (feeRecipient = env TREASURY_ADDRESS,
   buyTokenPercentageFee = env SWAP_FEE_BPS/10000, default 30bps). Env
   flag SWAPS_ENABLED=false gates the entire feature — routes return 403
   when off (same dormant-by-default discipline as the bridge).
3. TOKEN SAFETY: a server-side allowlist table of tradeable tokens on
   Base (start: ETH/WETH, USDC, cbBTC, AERO, DEGEN + admin CRUD behind
   requireAdminFlexible). Quotes refuse tokens off the list. Slippage
   default 0.5%, max 3%; quotes expire client-side at the 0x validity
   window with a visible countdown.
4. SWAP UI (client/src/pages/trade.tsx + components/trade/): ds-native
   swap card — token selects from the allowlist, amount with balance +
   MAX, live quote with price impact, fee line showing our fee
   transparently, approve-then-swap flow (use Permit2 where the route
   supports it), tx submission via wagmi, and a status tracker
   (pending/confirmed/failed with BaseScan link). Record every confirmed
   swap in a new user_trades table (wallet, tokens, amounts, tx_hash,
   fee_collected, quoted_price, executed_price, created_at).
5. RISK PLUMBING: riskEngine gains real-money checks — per-wallet daily
   quote-volume soft cap (env), price-impact hard block above 8% with
   override confirmation between 3-8%, and risk_events logging.
6. DISCLOSURE: first wallet connection shows a one-time modal (stored
   per wallet): non-custodial, you control your keys, crypto is
   volatile, StreamAiX charges a 0.3% swap fee, nothing here is
   investment advice. Persistent one-line fee+risk note on the swap card.
Tests: quote service with mocked 0x (fee params present, allowlist
enforcement, expiry), risk checks, SWAPS_ENABLED=false 403s. Gate: lint,
tests, build, zero new tsc errors. Push and verify.
