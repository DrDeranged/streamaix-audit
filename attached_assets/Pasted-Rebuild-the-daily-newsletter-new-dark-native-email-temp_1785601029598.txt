Rebuild the daily newsletter: new dark-native email template + five content
bug fixes. Files: server/services/newsletterTemplate.ts and
server/services/newsletterContentGenerator.ts. Do not touch the scheduler,
send path, or unsubscribe token logic.

PART 1 — TEMPLATE (newsletterTemplate.ts, full rewrite of generateNewsletterHTML):
The current template is hardcoded light-mode and gets destroyed by Apple Mail
dark-mode auto-inversion on iPhone. Replace with a dark-native design that
renders identically in light and dark clients. The design source of truth is
the attached file streamaix_newsletter_v2_1_preview.html — reproduce its
design faithfully as the template, converting the hardcoded sample data into
the existing NewsletterContent fields. Requirements that must survive the
port:

- <meta name="color-scheme" content="light dark"> AND
  <meta name="supported-color-schemes" content="light dark"> in head, plus
  :root { color-scheme: light dark; } in the style block.
- All layout via nested tables, all colors inline AND as bgcolor attributes
  on the cells that carry background color. 600px container, the same mobile
  media query pattern (.container/.px/.stack/.tape-cell).
- Palette exactly: page #080B14, card #10162A, border #232B45, row divider
  #1A2138, primary text #F2F4FA, body serif text #C9CEDC, secondary #9BA3B7,
  muted #7A8299, accent violet #A99DF8, button #8B7CF6 with #0E1220 text,
  gain #3DD68C, loss #FF7B7B, fear-gauge amber #FFB454. Footer disclaimer
  and unsubscribe text use #7A8299 (never anything fainter).
- Fear & Greed gauge: two-cell table bar whose filled-cell width% equals the
  index value, amber fill, with EXTREME FEAR / NEUTRAL / EXTREME GREED labels.
- Prediction market cards: question, a two-cell YES-odds bar (green fill
  width = yes%), then "X% YES · {vol} vol · {traders} traders · resolves
  {date}" using the market's real deadline.
- Movers: two side-by-side ledger columns (crypto | stocks), top 3 gainers +
  top 2 losers per column. Each ledger is a THREE-column table: ticker left;
  price in its own right-aligned column (font-size 12, color #9BA3B7,
  white-space:nowrap); percent in a right-aligned width="62" column, always
  signed, always two decimals ("+7.44%" / "&minus;3.64%"). Do not fold
  prices back into inline spans — every figure must share a hard right edge.
- Streams section shows times in ET. News section max 3 items.
- Footer disclaimer verbatim: "StreamAiX content is generated by AI systems
  for informational and entertainment purposes only. Nothing in this email is
  investment, financial, or trading advice. Market data may be delayed.
  Prediction markets on StreamAiX settle in platform points."
- Preheader div (hidden preview text) built from btcPrice, fearGreedIndex,
  and the top stock gainer.
- Keep generateNewsletterText in sync with the new structure.
- Every section must render nothing (skip cleanly) when its data array is
  empty — no empty cards, no headers over nothing.

PART 2 — CONTENT FIXES (newsletterContentGenerator.ts):
a. STALE MARKETS: fetchHotMarkets currently filters only status='active'.
   Add: deadline/resolution date must be in the FUTURE, and traders >= 25.
   If fewer than 2 markets qualify, include the largest future-dated market
   regardless of trader count rather than showing expired ones.
b. TIMEZONE: fetchUpcomingStreams builds 8:00/16:00 with setHours in server
   local time (UTC on Replit) — subscribers saw "4:00 AM EST". Construct the
   stream times explicitly in America/New_York (use Intl/date-fns-tz or
   toLocaleString with timeZone: 'America/New_York') and format labels as
   "8:00 AM ET" / "4:00 PM ET". Never hardcode "EST".
c. INDEX LABEL: the header ticker fetches SPY but labels it "S&P 500".
   Label it "SPY (S&P 500 ETF)" everywhere it appears.
d. THE AGENTS' BRIEF: delete generateMarketSummary and the if/else
   alphaInsight template logic (the "Risk-on mode / Consider momentum plays"
   branches). Replace both with ONE field, agentsBrief: a single 90-130 word
   paragraph generated through modelGateway.complete at tier 'reasoning',
   system prompt: financial newsletter editor; user prompt containing the
   actual numbers (BTC/ETH price+change, SPY change, fear/greed value, top 3
   stock gainers/losers with %, top crypto mover). Instructions to the
   model: be observational and specific, reference the real numbers, note
   tensions in the data (e.g. fear index vs rising prices), NEVER give
   advice — no "consider", "buy", "sell", "opportunity", no
   recommendations. Fallback if the gateway call fails: a plain factual
   sentence assembled from the numbers ("Bitcoin {chg} to {price}; sentiment
   at {fg}/100.") — never send the newsletter without a brief and never
   crash the send.
e. COPY: the "What's on StreamAiX" feature blurb says "50 autonomous AI
   trading bots" — change to "100 autonomous agents". Fix the double period
   in any fallback summary strings.

FORMATTING RULES: formatPrice: >= $1 → two decimals with thousands
separators; < $1 → four significant decimals. Percent formatting is always
toFixed(2) with an explicit sign.
